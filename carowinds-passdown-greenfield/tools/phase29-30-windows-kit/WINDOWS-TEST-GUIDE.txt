TROUBLESHOOTING
-------------------------------------------------------------------------------
- "Windows protected your PC": More info > Run anyway (the test build is not code-signed).
- A .cmd window closes at once or says scripts are disabled: open PowerShell in the scripts
  folder and run, for example,
     powershell -NoProfile -ExecutionPolicy Bypass -File .\Phase30-SyncTest.ps1 -Mode Inspect
  (This changes no system setting.)
- Prepare says the app is running: close it in both accounts, or sign the other account out.
- Prepare says the test folder already exists and is not empty: someone already prepared it.
  Do not delete it - report it.
- Check folder access shows [FAIL]: stop the sync part and report the window text.
- Clipboard checker says "The clipboard is in use": wait 5 seconds and run it again.
- Teams pasted everything as plain text: record it - that is a result, not your mistake.
- Teams sent a message by accident: delete it at once (it is fake data) and note it.
- About this build does not say 984d55c: you started another copy of the app. Close it and
  start the .exe from your CarowindsTest-29-30 folder.
- The status shows a conflict you did not expect: take a screenshot of the Review screen
  before choosing, then continue.
