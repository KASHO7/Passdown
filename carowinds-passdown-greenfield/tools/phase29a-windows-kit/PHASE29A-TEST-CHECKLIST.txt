PHASE 29A - MORNING MESSAGE + TEAMS PASTE TEST (Windows 11)
=============================================================

What you are testing: does "Copy Formatted" in the Morning Message put a message on the
Windows clipboard that pastes into Microsoft Teams with bold headings, bullets and
paragraph spacing - and do the old Copy options still work?

Time needed: about 60-90 minutes. No administrator rights needed. You never need to look
at source code. Write results in RESULTS.txt (a copy of the table at the end of this file).

Everything in this kit is FAKE test data. Never paste it into a real staff chat.


-------------------------------------------------------------------------------
WHAT IS IN THE KIT
-------------------------------------------------------------------------------
  LOCAL-ONLY-phase29a-morning-message-win-x64.zip   the test build of the app
  SHA256SUMS.txt                                    its fingerprint
  PHASE29A-TEST-CHECKLIST.txt                       this file
  synthetic-input\                                  text to paste into the app (fake data)
  expected\                                         what the copied message should look like
  scripts\                                          double-click checkers (read-only):
     1 Check Morning Message copy.cmd
     2 Check OD Notes copy.cmd
     3 Check any other copy.cmd
     4 Clipboard failure test.cmd

The checkers read the clipboard and write a report to Desktop\Phase29A-results\.
They change nothing. If Windows asks "Do you want to run this file?", choose Run.

STEP 0 - SAFETY FIRST (do not skip)
-------------------------------------------------------------------------------

         that was made for earlier validation. NOT your normal account.

         (Renaming keeps the earlier test data; you can rename it back later.)

[ ] 0.4  Do NOT double-click "Enable Automatic Refresh.cmd" in the app folder.
[ ] 0.5  If the app offers an update, click "Not now". Do not install updates from it.

         Never press Send. Before pasting, open the large compose box

TROUBLESHOOTING
-------------------------------------------------------------------------------
- "Windows protected your PC": More info > Run anyway (the test build is not code-signed).
- A checker window closes immediately or says scripts are disabled: right-click the .cmd >
  Run as (normal user is fine), or open PowerShell in the scripts folder and run
     powershell -NoProfile -ExecutionPolicy Bypass -File .\Inspect-TeamsClipboard.ps1 -Kind MorningMessage
  (This does not change any system setting.)
- Checker says "The clipboard is in use by another program": wait 5 seconds and run it again.
- Teams pasted everything as plain text: still record it (that is a result, not your
  mistake). Also try pasting with Ctrl+V in the large compose box, not the small one.
- Teams sent the message by accident: delete it right away (it is fake data) and note it.
- The app shows another user's or real data: STOP - you are in the wrong Windows account.
- About this build does not say fb6cc67: you started a different copy of the app. Close it
  and start the .exe from the LOCAL-ONLY folder.
