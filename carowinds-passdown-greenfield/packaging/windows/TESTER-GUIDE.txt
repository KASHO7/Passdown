Carowinds Operations 0.1.0-rc.7 — Tester Guide
================================================

Thanks for testing this app. You do not need any technical background. Follow the
steps below in order. If anything looks wrong or does not match this guide, see
"If something goes wrong" at the end.

Use made-up sample values only. Do not type anything private or real.


*** 1. BACK UP YOUR LOCAL DATA BEFORE FIRST LAUNCH ***
-------------------------------------------------------
Your saved passdowns, History, notes, settings and price history live in this
folder, NOT in the folder you extract the ZIP into:

    %LOCALAPPDATA%\Carowinds Passdown

Before you open this version for the first time:
  1. Close Carowinds Operations completely (check the taskbar).
  2. Make sure the automatic daily refresh is not running right now (it runs
     briefly around 6:00 AM; if in doubt, wait a few minutes or restart the PC).
  3. Press Windows+R, type  %LOCALAPPDATA%  and press Enter.
  4. Right-click the "Carowinds Passdown" folder, choose Copy, and paste it
     somewhere OUTSIDE that folder (for example your Documents folder).
  5. Rename the copy to include today's date, e.g.
     "Carowinds Passdown backup 2026-10-18", and write down where you put it.
  6. Never copy a backup back while the app is open.

Going back to an older version: copying an older app over this one is NOT a safe
way to undo the upgrade. If you ever need to go back, close the app, put your
dated backup folder back in place, and then run the older version.


*** 2. UPGRADE ALL COMPUTERS SHARING A SYNC FOLDER TOGETHER ***
----------------------------------------------------------------
If more than one computer uses Personal Sync with the same shared folder:
  - Install this version on EVERY one of those computers before you use the
    "Shows" section.
  - Older versions may not understand the latest Show draft selections and may
    discard them on re-save. That loss then syncs to the other computers.
  - The app does NOT stop an older version from saving. Upgrading everything
    together is the only protection.
  - Back up the shared sync folder (copy it somewhere else) before testing on
    two computers for the first time.
  - Use a NEW, empty test folder for sync testing (step 13), not your real
    shared work folder, unless whoever asked you to test says otherwise.


3. Extract the ZIP
-------------------
Right-click Carowinds-Operations-0.1.0-rc.7-win-x64.zip and choose
"Extract All...". Pick a NEW, empty folder you can write to (Desktop, Documents).
Do NOT run the app from inside the ZIP without extracting it first.

Do not extract on top of an older version's folder.


4. Start the app
-----------------
Open the extracted folder and double-click  Carowinds.Passdown.Desktop.exe.
The app should open in a few seconds. Nothing else needs to be installed first
(no .NET download, no admin rights).

If Windows shows a blue "Windows protected your PC" box, click "More info" and
then "Run anyway" only if you got the ZIP from the person who asked you to test.


5. Check the version
---------------------
Click the gear icon (Settings) at the right end of the navigation strip, scroll to
"About this build". It should say:

    Version 0.1.0-rc.7 (followed by a short code in brackets)
    Running from  <the folder you just extracted>

If it shows an older number, or a different folder, you opened an older copy (for
example through Windows Search or the Start menu). Close it and start
Carowinds.Passdown.Desktop.exe from the folder you just extracted.

About the single .exe file: you may also see
Carowinds-Operations-0.1.0-rc.7-win-x64-singlefile.exe. It is EXPERIMENTAL.
Please test with the ZIP. The single .exe does not carry the license notices or
the automatic-refresh helpers, so it must not be handed out on its own.


6. Look around the main screens
--------------------------------
At the top you should see the Fury 325 banner with "CAROWINDS OPERATIONS", and
the navigation:  Dashboard · Calendar · Passdown · Notes · History  plus the
Settings gear. The current screen is underlined.

Dashboard (opens first)
  - Operations Overview: today's park hours, the official daily park ticket price
    ("From $…" means a starting price; a plain price is exact), attendance and
    pre-solds with commas (for example 38,500).
  - Data Status: click to expand and collapse the source details. Problems stay
    visible even when it is collapsed.
  - Today's Shows: upcoming official show times.
  - "Open Passdown" goes to today's passdown; "Open Notes" goes to its notes.

Calendar
  - Click "Next ›" a few times. Months up to about a year ahead should show
    official hours or "Not Published". Nothing should be invented.
  - In December, WinterFest weekends and New Year's Eve (closing after midnight)
    should show real hours.
  - Click several dates quickly, one after another. The details on the right must
    always belong to the LAST date you clicked, never the one before.
  - Shows are collapsed under a short summary; "View schedule" expands them.
  - "Open Passdown" opens the passdown for the selected date.

Passdown (Associate Passdown)
  - Date bar: "‹" and "›" move one day, clicking the date opens a small calendar,
    "Today" jumps back. Changing the date should feel instant and does not need
    the internet.
  - Buttons: "Check Online", "Create PDF", "Copy ▾" (Teams text), "More ▾"
    (PDF style and Season Price History).
  - Sections: Overview, Products, Notes.
  - Type an attendance number such as 38500 and click elsewhere: it should change
    to 38,500. The cursor should not jump while you type.
  - The small "Draft" chip at the top right says when your changes were saved
    ("Saved on this computer at … ET").

Notes (Operational Notes)
  - Create a test note, edit it, try the filters, and resolve it. Times show
    "ET" (Eastern time).

History
  - Finalized passdowns are read-only. "Open Final PDF" opens the original stored
    PDF. Records from before this upgrade must still be there and unchanged.


7. Close and reopen
--------------------
Close the app completely, start it again, go back to the same date, and confirm
everything you typed is still there.


8. Try "Check Online"
----------------------
Click "Check Online" on the Passdown screen. It checks Carowinds' official
sources for the selected date and may take a few seconds. Without internet it
should fail politely and keep the last good information. That is expected.


9. Create PDFs
---------------
On the Passdown screen, fill in sample attendance, pre-solds, a note, tick two or
three Shows, and add a Daily Feature (the "∑ Math" button can insert a formula,
for example \(\frac{d}{dx}x^2=2x\)).

Then for EACH style (More ▾ → PDF Style: Classic, Compact, Modern):
  1. Click "Create PDF" and save it to your Desktop.
  2. Open it and check: prices (including "From" prices), attendance with commas,
     the formula drawn properly, Shows at the END (after Operational Notes), the
     date and time at the bottom of the page, and nothing cut off.

Then try "Copy ▾" and each of its three options, paste into Notepad, and confirm
the text has no Shows and no Daily Feature.


10. Check screen scaling
-------------------------
Open Windows Settings › System › Display › "Scale". For each of 100%, 125% and
150%:
  - Look at Dashboard, Calendar, Passdown, Notes, History and Settings.
  - Make the window small (drag a corner as small as it goes) and then
    maximized.
  - Nothing should be cut off or overlap, and you should never need to scroll
    sideways.
Note anything that looks wrong, with the scale value and a screenshot
(Windows+Shift+S).

Also try Light and Dark: Windows Settings › Personalization › Colors ›
"Choose your mode". The app should follow while it is open.


11. Keyboard and Narrator (optional, but very helpful)
-------------------------------------------------------
  - Press Tab repeatedly on each screen: a visible focus outline should move in a
    sensible order. Enter or Space should press the focused button.
  - Turn on Narrator (Ctrl+Windows+Enter). Move through the navigation, the
    Settings gear, the Calendar day cells and the Shows "View schedule" button.
    Write down anything Narrator reads as just "button" or does not read at all.
    Ctrl+Windows+Enter turns Narrator off again.


12. Settings
-------------
  - Appearance and Data Refresh only explain how the app behaves.
  - Diagnostics: "Export Diagnostics…" saves one ZIP with version and health
    information and recent logs. It does NOT contain your drafts, notes, PDFs or
    database.
  - About this build: version and folder (see step 5).


13. Personal Sync (only on test folders)
-----------------------------------------
Only do this with a NEW, empty test folder (for example a new folder in OneDrive
called "Carowinds sync test"). Do not point it at your real shared work folder
unless whoever asked you to test has said so and you backed that folder up.

  1. Settings › Personal Sync › "Enable Personal Sync", then "Choose Folder…" and
     pick the test folder (this opens the normal Windows folder picker).
  2. Click "Sync Now". "Last synced … ET" should update.
  3. If you have a second test PC with this same version: point it at the same
     test folder, make a different change to the same date on each PC, then
     "Sync Now" on both. The app should show a conflict for you to review
     ("Review Conflicts"), not silently overwrite one PC's change.
  4. Disconnect from the internet and confirm the app still opens and works from
     local data.


14. Turn on automatic daily refresh (optional)
-----------------------------------------------
Only if whoever asked you to test wants this checked. In the extracted folder,
double-click "Enable Automatic Refresh.cmd". A small window reports whether it
worked and waits for a key press. You can check Windows "Task Scheduler" for a
task named "Carowinds Passdown Daily Refresh". To turn it off again, double-click
"Disable Automatic Refresh.cmd".

If you move the app folder later, run "Enable Automatic Refresh.cmd" again from
the new location.


15. Save-failure check (testers asked to do this only)
-------------------------------------------------------
This version shows "Save failed — changes not saved" in the Draft chip when the
app genuinely cannot save (hover over it to see why). If you are asked to test
this by making the data folder read-only:
  - Make the change, check the chip text, then make the folder writable again
    BEFORE you change the date, click Check Online, or add a note.
  - Known problem in this version: while saving keeps failing, changing the date,
    Check Online or adding a note can make the app freeze. If it freezes, close
    it with Task Manager, make the folder writable again, and reopen it. This is
    planned to be fixed in the next version.


16. If something goes wrong
----------------------------
  - Write down exactly what you were doing, what you expected, and what happened
    instead. Include the Windows display scale and Light/Dark mode.
  - Take a screenshot (Windows+Shift+S).
  - Settings › Diagnostics › "Export Diagnostics…", save the ZIP.
  - Send the notes, screenshots and diagnostics ZIP to whoever asked you to test.
  - Do not delete anything under %LOCALAPPDATA%\Carowinds Passdown while
    troubleshooting — that folder holds your saved data.

That's the full test. Thank you!
