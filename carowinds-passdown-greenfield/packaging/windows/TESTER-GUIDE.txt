Carowinds Operations 0.1.0-rc.15 — Tester Guide
=================================================

Thanks for testing this app. You do not need any technical background. Follow the
steps below in order. If anything looks wrong or does not match this guide, see
"If something goes wrong" at the end.

Use made-up sample values only. Do not type anything private or real.


*** 1. BACK UP YOUR LOCAL DATA BEFORE FIRST LAUNCH ***
-------------------------------------------------------
Your saved passdowns, History, notes, settings and price history live in this
folder, NOT in the folder you extract the ZIP into:

    %LOCALAPPDATA%\Carowinds Passdown

Before you open this version for the first time:
  1. Close Carowinds Operations completely (check the taskbar).
  2. Make sure the automatic daily refresh is not running right now (it runs
     briefly around 6:00 AM; if in doubt, wait a few minutes or restart the PC).
  3. Press Windows+R, type  %LOCALAPPDATA%  and press Enter.
  4. Right-click the "Carowinds Passdown" folder, choose Copy, and paste it
     somewhere OUTSIDE that folder (for example your Documents folder).
  5. Rename the copy to include today's date, e.g.
     "Carowinds Passdown backup 2026-10-18", and write down where you put it.
  6. Never copy a backup back while the app is open.

Going back to an older version: copying an older app over this one is NOT a safe
way to undo the upgrade. If you ever need to go back, close the app, put your
dated backup folder back in place, and then run the older version.

Coming from rc.11, rc.12, rc.13 or rc.14 there is no database change. Coming from rc.10 or
older, this version changes the format of the app's database the first time it starts (it
adds one table for official reference pages; nothing you saved is changed).
Before it does, it saves its own checked copy in the "backups" folder inside
%LOCALAPPDATA%\Carowinds Passdown. Your own dated backup (above) is still the
safest way back: rc.10 and older CANNOT open the updated database.


*** 2. UPGRADE ALL COMPUTERS SHARING A SYNC FOLDER TOGETHER ***
----------------------------------------------------------------
If more than one computer uses Personal Sync with the same shared folder:
  - Install this version on EVERY one of those computers before you use the
    "Shows" section.
  - Older versions may not understand the latest Show draft selections and may
    discard them on re-save. That loss then syncs to the other computers.
  - The app does NOT stop an older version from saving. Upgrading everything
    together is the only protection.
  - Back up the shared sync folder (copy it somewhere else) before testing on
    two computers for the first time.
  - Use a NEW, empty test folder for sync testing (step 13), not your real
    shared work folder, unless whoever asked you to test says otherwise.
  - Official price history is now shared through the sync folder too, but only
    between computers running this version. Older versions keep syncing drafts
    and notes and simply ignore the price history.


3. Extract the ZIP
-------------------
Right-click Carowinds-Operations-0.1.0-rc.15-win-x64.zip and choose
"Extract All...". Pick a NEW, empty folder you can write to (Desktop, Documents).
Do NOT run the app from inside the ZIP without extracting it first.

Do not extract on top of an older version's folder.


4. Start the app
-----------------
Open the extracted folder and double-click  Carowinds.Passdown.Desktop.exe.
The app should open in a few seconds. Nothing else needs to be installed first
(no .NET download, no admin rights).

If Windows shows a blue "Windows protected your PC" box, click "More info" and
then "Run anyway" only if you got the ZIP from the person who asked you to test.


5. Check the version
---------------------
Click "Settings" at the bottom of the navigation on the left, then "About" in the
list of Settings sections. "About this build" should say:

    Version 0.1.0-rc.15 (followed by a short code in brackets)
    Running from  <the folder you just extracted>

If it shows an older number, or a different folder, you opened an older copy (for
example through Windows Search or the Start menu). Close it and start
Carowinds.Passdown.Desktop.exe from the folder you just extracted.

About the single .exe file: you may also see
Carowinds-Operations-0.1.0-rc.15-win-x64-singlefile.exe. It is EXPERIMENTAL.
Please test with the ZIP. The single .exe does not carry the license notices or
the automatic-refresh helpers, so it must not be handed out on its own. It also
cannot update itself: its Settings › Application Updates says "Manual update
required".

Installing this version by hand from the ZIP (as described above) does NOT open
"What's New" when it first starts — that only happens after an update installed
from inside the app. Only use rc.14's in-app "Install Update" for rc.15 if whoever
asked you to test gave you a special test update and a backed-up test profile.

If you used a special pre-release test build before (its About shows a longer
version that starts with 0.1.0-rc.15), it will not offer rc.15 as an update.
Extract this ZIP into a new folder instead.


6. Look around the main screens
--------------------------------
The window's title bar is navy with the original app icon and the name
"Carowinds Operations" (minimize, maximize and close work as in any Windows
app). On the left is the navigation: Dashboard, Calendar, Passdown, Operational
Notes, History, and Settings at the bottom. The current screen is highlighted
with a bar at its left edge. The button above the list collapses the navigation
to icons only and expands it again; the choice is remembered on this computer.
In a narrow window the navigation shows icons only.

Dashboard (opens first, titled "Admissions Overview")
  - Gate card: today's park operating hours, Avenue Entrance, North Gate and
    Early Ride Time, how each was set, and when it was last verified.
    "View in Calendar" opens the same date in the Calendar.
  - Today's Associate Passdown: draft status, attendance and pre-solds with
    commas (for example 38,500), "Open Passdown" and "Review Notes".
  - Shows & Entertainment: upcoming official show times with "+N more" for a
    long list; "View Shows" opens the Passdown's Shows tab.
  - Daily Ticket Pricing: only today's exact official dated prices ("View
    Pricing" opens Products). Operational Notes and the month's Pass Perks
    are summarized with links to their screens.
  - Official Data: the overall data status; "View Source Details" expands the
    per-source list. Nothing on the Dashboard is invented: blank values say
    "Not entered" or "Not available".
  - Weather: conditions from a nearby National Weather Service station (named,
    with its time), today's forecast high and low, the rain chance during park
    hours and any official NWS alerts. It appears a few seconds after the app
    opens; Refresh Weather is in the expanded weather details. Without internet
    it shows the last weather received and says when it may be out of date.
    The app never asks for or uses your computer's location.

Calendar
  - Click "Next ›" a few times. Months up to about a year ahead should show
    official hours or "Not Published". Nothing should be invented.
  - In December, WinterFest weekends and New Year's Eve (closing after midnight)
    should show real hours.
  - Click several dates quickly, one after another. The details on the right must
    always belong to the LAST date you clicked, never the one before.
  - Shows are collapsed under a short summary; "View schedule" expands them.
  - "Open Passdown" opens the passdown for the selected date.
  - Pass Perks: after "Check Online", days with officially advertised monthly
    Pass Perks show small markers in the same place in each day cell
    (qualifying visit, redemption / use, booking deadline), explained by a
    one-line legend under the grid. Hover a marker for its description; "View
    details" opens the perk's eligibility, requirements and official terms.
    The list is the public program, not anyone's personal rewards.
  - "Show Perks" above the grid (and Settings › Calendar) hides and restores the
    markers at once, and the choice survives a restart.
  - Weather: the selected date's panel shows a short forecast for the park
    hours, with an hourly list you can expand. Past dates and dates beyond the
    forecast show no weather values. The day cells never show weather, and
    clicking dates never goes online.
  - Daily ticket: after the park closes, a price checked earlier that day shows
    "last verified" with its date. It is the last official price, not a sign
    that tickets are still on sale.

Passdown (Associate Passdown)
  - Date bar: "‹" and "›" move one day, clicking the date (for example
    "Nov 26, 2026") opens a small calendar. "Today" appears only when you are
    on another date and jumps back. Changing the date should feel instant and
    does not need the internet.
  - Buttons: "Create PDF" and "Actions ▾". Actions holds Print (Ctrl+P), Save
    PDF, the three "Copy for Teams" options, Show / Hide Preview, PDF Style
    (Classic, Compact, Modern), Check Online and Season Price History.
  - Live preview: the real PDF appears beside the editor and stays there while
    you switch between Overview, Products, Shows and Notes. A single change (a checkbox,
    a product or a show) appears almost at once; while you keep typing it
    refreshes again shortly after you pause. Drag the divider to resize it; use the page arrows, zoom,
    Fit width and Fit page. Hide Preview gives the editor the whole width. The
    layout and zoom are remembered on this computer after a restart.
  - Sections (tabs): Overview, Products, Shows, Notes.
  - Products: click a price's edit button to open a small price editor next to
    it. Enter saves, Esc cancels, "Use official price" removes your display
    price. Only one editor is open at a time.
  - Shows: tick which shows print; "Select all" / "Clear"; a long schedule
    expands with "View times".
  - Notes: daily notes print one note per non-empty line. Ticking a persistent
    Operational Note only includes it in this passdown; it never edits or
    resolves the note.
  - Overview › Include in Passdown lists the sections that print, including
    Operational Notes, Shows and Weather Outlook (a small park-hours forecast,
    printed only when a current forecast covers those hours; it never shows
    alerts). Settings › Passdown Defaults › "Include Weather Outlook by default"
    is the same setting. The Shows section picks WHICH shows print;
    unchecking Shows under Include in Passdown keeps your picks but stops them
    printing.
  - Type an attendance number such as 38500 and click elsewhere: it should change
    to 38,500. The cursor should not jump while you type.
  - The save status near the top says when your changes were saved
    ("Saved on this computer at … ET").

Operational Notes
  - "New Note" opens a small editor over the page: Esc or Cancel closes it
    without saving. Create a test note, edit it, try the search and filters,
    and resolve it (Resolve asks you to confirm). Times show "ET" (Eastern time).

History
  - Finalized passdowns are read-only. "Open Final PDF" opens the original stored
    PDF and "Save PDF Copy" saves a copy of it; neither creates a new PDF.
    Search and the filters only narrow the list. Records from before this
    upgrade must still be there and unchanged.


7. Close and reopen
--------------------
Close the app completely, start it again, go back to the same date, and confirm
everything you typed is still there.


8. Try "Check Online"
----------------------
Click Actions ▾ → "Check Online" on the Passdown screen (or "Check Online" on
the Dashboard). It checks Carowinds' official
sources for the selected date and may take a few seconds. Without internet it
should fail politely and keep the last good information. That is expected.

Then look at Products:
  - Silver, Gold and Prestige Season Passes appear separately, each with its own
    price. A renewal offer, if shown, is labelled as a renewal.
  - Memberships appear as their own products. Monthly prices say "/month", and a
    one-time initiation fee is listed separately.
  - Under the Season Passes and Memberships source note, click "View Official
    Memberships & Season Passes Page". Your web browser should open that page
    on sixflags.com.
  - Actions ▾ → Season Price History still shows the older prices you had before.
  - Current Deals lists official offers (for example Black Friday deals) as
    short rows. "View details" opens the terms, deadlines and official page in
    a window; Esc or Close returns to the list.


9. Create PDFs
---------------
On the Passdown screen, fill in sample attendance, pre-solds, a note, tick two or
three shows in the Shows section (and keep Shows checked under Overview ›
Include in Passdown), and add a Daily Feature (the "∑ Math" button can insert a formula,
for example \(\frac{d}{dx}x^2=2x\)).

Then for EACH style (Actions ▾ → PDF Style: Classic, Compact, Modern):
  1. Click "Create PDF" and save it to your Desktop.
  2. Open it and check: prices (including "From" prices), attendance with commas,
     the formula drawn properly, Shows at the END (after Operational Notes), the
     date and time at the bottom of the page, and nothing cut off.

Then, with the preview showing, try "Save PDF" in the preview toolbar and
"Print" (Actions ▾ → Print, Ctrl+P, and the preview toolbar). Print opens the normal
Windows print dialog; pick a printer (or "Microsoft Print to PDF"), print one
copy and check it matches the preview. Pressing Cancel prints nothing.

Then try each of the three "Copy for Teams" options under Actions ▾, paste into Notepad, and confirm
the text has no Shows and no Daily Feature.


10. Check screen scaling
-------------------------
Open Windows Settings › System › Display › "Scale". For each of 100%, 125% and
150%:
  - Look at Dashboard, Calendar, Passdown, Notes, History and Settings.
  - Make the window small (drag a corner as small as it goes) and then
    maximized.
  - Nothing should be cut off or overlap, and you should never need to scroll
    sideways.
Note anything that looks wrong, with the scale value and a screenshot
(Windows+Shift+S).

Also try Light and Dark: Windows Settings › Personalization › Colors ›
"Choose your mode". With the app's Appearance set to "Use Windows setting" (the
default) the app should follow while it is open. Then in the app's Settings ›
Appearance choose "Light" while Windows is Dark, and "Dark" while Windows is
Light: the app should switch at once and stay on your choice. Close and reopen
the app: your choice should still apply, with no flash of the other theme.


11. Keyboard and Narrator (optional, but very helpful)
-------------------------------------------------------
  - Press Tab repeatedly on each screen: a visible focus outline should move in a
    sensible order. Enter or Space should press the focused button.
  - Turn on Narrator (Ctrl+Windows+Enter). Move through the navigation, Settings,
    the Calendar day cells, the Products price editor and the Shows "View
    times" button.
    Write down anything Narrator reads as just "button" or does not read at all.
    Ctrl+Windows+Enter turns Narrator off again.


12. Settings
-------------
  - Appearance: Use Windows setting, Light or Dark (see step 10). The choice is
    saved on this computer only; it is not shared through Personal Sync.
  - Interface animations: On by default. Off removes the small sidebar and
    hover animations. If Windows "Animation effects" is off, the app stays
    still even when this says On, and your choice is kept.
  - Passdown Defaults: choose which sections start checked when you open a
    date you have not used yet. Operational Notes is checked by default. Dates
    you already started keep their own choices. Saved on this computer only.
  - Data Refresh only explains how the app behaves.
  - Application Updates: "Check for Updates" looks for newer approved versions.
    It is fine if it says you are up to date or that it could not check. Do
    NOT install anything from here unless whoever asked you to test gave you
    a special test update.
  - Diagnostics: "Export Diagnostics…" saves one ZIP with version and health
    information and recent logs. It does NOT contain your drafts, notes, PDFs or
    database.
  - About this build: version and folder (see step 5), and a "What's New"
    button that shows this version's notes, even without internet.


13. Personal Sync (only on test folders)
-----------------------------------------
Only do this with a NEW, empty test folder (for example a new folder in OneDrive
called "Carowinds sync test"). Do not point it at your real shared work folder
unless whoever asked you to test has said so and you backed that folder up.

  1. Settings › Personal Sync › "Enable Personal Sync", then "Choose Folder…" and
     pick the test folder (this opens the normal Windows folder picker).
  2. Click "Sync Now". "Last synced … ET" should update.
  3. If you have a second test PC with this same version: point it at the same
     test folder, make a different change to the same date on each PC, then
     "Sync Now" on both. The app should show a conflict for you to review
     ("Review Conflicts"), not silently overwrite one PC's change.
  4. Disconnect from the internet and confirm the app still opens and works from
     local data.


14. Turn on automatic daily refresh (optional)
-----------------------------------------------
Only if whoever asked you to test wants this checked. In the extracted folder,
double-click "Enable Automatic Refresh.cmd". A small window reports whether it
worked and waits for a key press. You can check Windows "Task Scheduler" for a
task named "Carowinds Passdown Daily Refresh". To turn it off again, double-click
"Disable Automatic Refresh.cmd".

If you move the app folder later, run "Enable Automatic Refresh.cmd" again from
the new location.


15. Save-failure check (testers asked to do this only)
-------------------------------------------------------
Only use a test copy of your data for this (back up first, step 1).
This version shows "Save failed" in the save status near the top of the Passdown
screen when the app genuinely cannot save (hover over it to see why), and a "Retry Save" button.
If you are asked to test this by making the data folder read-only:
  - Make a change and check the save status text and the Retry Save button.
  - Try changing the date, Check Online, and adding a note. Each should be
    refused with an explanation. The app must NOT freeze, and Task Manager
    should not show it using lots of CPU.
  - Make the folder writable again and click Retry Save. The save status should
    say the changes were saved, and your edits should still be there.
  - Closing the app while the save is failing shows a warning the first time.
    Closing a second time closes the app and your unsaved changes are lost.
  - A save can occasionally take up to about five seconds if the data file is
    busy; that is expected.


16. If something goes wrong
----------------------------
  - Write down exactly what you were doing, what you expected, and what happened
    instead. Include the Windows display scale and Light/Dark mode.
  - Take a screenshot (Windows+Shift+S).
  - Settings › Diagnostics › "Export Diagnostics…", save the ZIP.
  - Send the notes, screenshots and diagnostics ZIP to whoever asked you to test.
  - Do not delete anything under %LOCALAPPDATA%\Carowinds Passdown while
    troubleshooting — that folder holds your saved data.

That's the full test. Thank you!
