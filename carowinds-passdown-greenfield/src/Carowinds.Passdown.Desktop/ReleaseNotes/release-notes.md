## Price history

- Season Pass price history now shows every check from all your computers in one place.
- Before, a computer that started using the app after the Carowinds website was redesigned could hide another computer's older Gold and Prestige Season Pass prices under "Include retired products".
- Nothing stored was changed. The full history simply appears where you expect it.

## Your data

- This version uses the same database as RC.9, so nothing is changed when it first starts after RC.9.
- If you are coming straight from RC.8 or earlier, the database is updated the first time it starts, and a checked copy is saved in the backups folder inside %LOCALAPPDATA%\Carowinds Passdown first.

Your drafts, notes, History PDFs, Personal Sync settings and appearance choice are kept.
